ต่ำกว่าเกณฑ์นี้ระบบจะส่งต่อพนักงานทันที (อ้างอิง NFR-03)

เชื่อมต่อ LLM API จริง (ให้ AI ใช้ Prompt Engineering เต็มรูปแบบ)

เมื่อเปิดใช้งาน ระบบจะส่ง System Prompt + Few-shot + ฐานความรู้ที่เกี่ยวข้อง + ประวัติการสนทนา ไปให้ LLM จริงประมวลผลและตอบกลับแบบ Generative (ไม่ตายตัวเหมือนโหมดจำลอง) หากเรียก API ไม่สำเร็จ ระบบจะ fallback กลับไปใช้ Rule-based Engine ให้อัตโนมัติ

📌 ขอ API Key ฟรีได้ที่ aistudio.google.com/apikey (ล็อกอินด้วย Google Account แล้วกด "Create API key" ใช้เวลาไม่ถึง 1 นาที ไม่ต้องผูกบัตรเครดิต)

⚠️ วิธีนี้เรียก API ตรงจากเบราว์เซอร์ (client-side) เหมาะกับการทดสอบ/สาธิตในชั้นเรียน หากนำไปใช้งานจริงกับลูกค้าทั่วไป ควรย้าย API Key ไปไว้ฝั่ง Backend เพื่อความปลอดภัย (ดูหัวข้อ "แนวทางพัฒนาต่อ" ในเอกสารประกอบ)
